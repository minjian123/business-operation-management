## 简介

**biz（企业运营管理）** 是 BMS 平台之上的独立业务产品：承载采购、收付款、供应商、销售、仓储等企业运营业务，独立仓库、独立演进，运行时作为 **BMS 平台扩展**（前端模块合并、后端扩展包并入 BMS 进程）复用平台能力（认证/RBAC/文件/通知/工作流/报表/审计等），自身只做运营业务域。

> 业务原为 BMS 规划中的自营模块，随《平台可扩展性规划》「业务不入平台」原则整体迁出独立立项；平台能力不重复实现，机制见 bms 仓库《平台可扩展性规划》与《项目规划说明》。

## 文档

> 全部文档位于 `biz文档/` 目录，入口为《[文档首页](biz文档/文档首页.md)》（全量导航）。正文以 Markdown 为载体，线框图/可交互原型保留 `.html` 资产。

> 工作区模型：本仓库与 `bms` 克隆平级置于工作区（如 `bizs/`）；基座目录以符号链接引用 bms，基座只在 bms 仓库演进、靠 git 同步（见 bms《平台可扩展性规划》4.3）。

## 目录结构

```text
biz/
├── README.md                 # 本文件
├── LICENSE                   # MIT 许可
├── AGENTS.md                 # AI 协作约定
├── deploy/                   # 部署配置
│   └── .env.example          # 凭据模板
├── ops/                      # 运维脚本（后续阶段填充）
└── biz文档/                  # 项目文档
    ├── 文档首页.md            # 全量导航
    ├── 规划/                 # 1篇：《biz 企业运营管理规划》
    ├── 项目/                 # 需求/任务/计划基线（随开发阶段填充）
    ├── 设计/                 # 运营体系设计（总纲+节点）
    │   ├── 架构设计/          # 总体架构（业务外置与平台接入）
    │   ├── 概要设计/          # 采购/收付款/供应商/销售/仓储模块设计
    │   └── 原型设计/          # 可交互界面原型（01 总览 + 02 采购 + 共享资源）
    ├── 规范/                 # 符号链接 → ../../bms/bms文档/规范（19 篇通用基座）
    ├── 资料/                 # 基座子目录为软链 → bms；产品专属资料为实目录（后续填充）
    ├── 用户文档/             # 本地资源（机器凭据等，已 gitignore）
    └── 资源/                 # 符号链接 → ../../bms/bms文档/资源（共享样式与 mermaid 脚本）
```

> 凭据统一存 `deploy/.env`（已 gitignore，模板见 `deploy/.env.example`）。
