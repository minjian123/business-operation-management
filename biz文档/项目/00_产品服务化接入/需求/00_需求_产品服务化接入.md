## 1. 文档说明 <a id="purpose"></a>

本文档是 biz「00 产品服务化接入」阶段的需求总览：承载本阶段目标与范围、需求总清单；阶段任务与排期见[《01_计划_产品服务化接入》](../计划/01_计划_产品服务化接入.md)。

本阶段为 bms 微服务改造定案（2026-09-22）后的产品侧形态对齐——biz 接入形态由「进程内扩展包」改为「产品服务（独立服务）」，并将 biz 文档体系统一到可供后续接入开发直接使用的基线。

- 依据：bms《微服务演进规划》第 3 批、《平台可扩展性规划》「业务承载路径的取舍」节、《架构设计 · 模块注册》「服务目录与契约登记」「独立接入边界」节（`bms文档/…`）；
- 规范：bms《需求文档规范》《任务文档规范》《计划文档规范》（基座）。

## 2. 产品服务化接入目标与范围 <a id="goal"></a>

**范围内**：

1. biz 文档接入形态口径对齐（规划 / 架构设计 / 概要设计 / README / 文档首页 / 本地规范）；
2. 五模块服务标识与服务目录登记口径对齐（与 bms 服务目录 `service_key` 一致）；
3. biz 项目阶段体系建立（需求 / 任务 / 计划 / 详细设计 / 实施记录）。

**范围外**：

- 代码接入（biz 后端 / 前端工程）——待 bms 产品服务接入机制（R4.1~R4.3）就绪后另立阶段；
- 业务域扩展候选与暂缓域的实施——按《[biz 企业运营管理规划](../../../规划/biz企业运营管理规划.md)》演进路线推进。
