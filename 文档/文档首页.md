## 1. 用途说明 <a id="purpose"></a>

本文档是 `文档/` 目录的**全量索引**，汇总 biz 项目全部规划、规范、资料与设计文档，按目录分类提供跳转入口。biz 为 BMS 平台扩展产品：**通用规范与共享资料为统一基座，权威源在 bms 仓库，经 base-sync 订阅同步**；本仓库上层只放产品专属内容（规划、业务设计、专属资料）。文件格式约定：正文载体不限（`.md` / `.html`），线框图/可交互原型用 `.html` 资产（见《[文档生成规范](规范/文档生成规范.md)》）。

## 2. 目录结构总览 <a id="structure"></a>

```text
文档/
├── 规划/       # 项目级规划文档（产品专属）
├── 项目/       # 按阶段的项目基线（随开发阶段填充）
├── 设计/       # 运营体系设计（总纲 + 节点，随开发阶段填充）
├── 规范/       # 19 篇开发与文档规范（通用基座，权威源 bms）
├── 资料/       # 基础设施资料（基座，源自 bms 同步）+ 产品专属（后续填充）
├── 用户文档/   # 本地资源（机器凭据等，已 gitignore）
└── 资源/       # 文档共享样式与 mermaid 脚本（基座，源自 bms 同步）
```

| 文件夹 | 用途 | 典型文档 |
| --- | --- | --- |
| `规划/` | 产品顶层规划：定位、功能模块、平台复用边界、演进路线 | 《项目规划说明》 |
| `项目/` | 按阶段的项目基线：需求 / 任务 / 计划 | 随开发阶段填充 |
| `设计/` | 运营体系设计：设计总纲 + 采购/收付款/供应商/销售/仓储模块设计节点 | 随开发阶段填充 |
| `规范/` | 通用基座（权威源 bms，订阅同步）：文档怎么写、标识符怎么命名、前后端代码规范 | 《文档生成规范》《命名规范》等 19 篇 |
| `资料/` | 基础设施资料（基座，源自 bms 同步）+ 运营业务专属参考 | 随开发阶段填充 |

> 浏览建议：先读「规划」（本产品定位与范围），机制不明时查 bms《平台可扩展性规划》与《项目规划说明》，开发时遵循「规范」回刷基座。
